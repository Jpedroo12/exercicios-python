# Exercícios de Python 🐍

Repositório com exercícios e práticas desenvolvidos durante meus estudos de Python.

O objetivo é registrar minha evolução, praticar lógica de programação e consolidar os fundamentos da linguagem.

## Organização

| Pasta | Conteúdo |
|---|---|
| `01_fundamentos_basicos` | Entrada e saída de dados, variáveis, tipos e operadores |
| `02_manipulacao_de_strings` | Métodos e operações com textos |
| `03_modulos_math` | Uso dos módulos `math` e `random` |
| `04_condicoes_simples` | Estruturas condicionais |
| `05_condicoes_aninhadas` | Condições encadeadas e aninhadas |
| `06_estruturas_de_repeticao` | Estruturas `for` e `while` |

## Tecnologias

- Python 3
